# CodeAlpha_PhishingAwarenessTraining
**CodeAlpha Cyber Security Internship — Task 2**

## Overview
This project is a phishing awareness training presentation created as part of the CodeAlpha Cyber Security Internship. It covers how to recognize phishing emails and fake websites, common social engineering tactics used by attackers, a real-world example, best practices for staying safe, and a short quiz to test understanding.

## Contents
- `CodeAlpha_PhishingAwarenessTraining.pptx` — the full training presentation

## Topics Covered
- What phishing is and why it works
- Red flags in phishing emails
- Red flags in fake websites
- Social engineering tactics (authority impersonation, urgency, familiarity exploitation, reward bait)
- A real-world case study
- Best practices checklist
- A short self-test quiz
